# Безопасность и чувствительные данные

## Что хранится

- Если указана опция `-log-file`, журнал добавляется в выбранный файл. По
  умолчанию журнал выводится в stdout.
- Для подписки последняя успешная загрузка сохраняется в
  `cache/subscription.json` относительно текущей рабочей директории. Кэш
  содержит список профилей целиком, включая UUID, и ограничен размером 10 MiB.
  На POSIX кэш создаётся с правами владельца (`0600`), на Windows для файла
  устанавливается защищённая DACL, разрешающая доступ только текущему
  пользователю.
- Профиль из `-config` читается из указанного JSON-файла. Программа не
  шифрует его и не копирует автоматически в отдельное хранилище.
- Параметр `-link` передаётся как аргумент процесса; он может быть виден
  локальным средствам аудита процессов или истории оболочки.
- На Windows при `-system-proxy` значения системного прокси записываются в
  настройки Internet Settings текущего пользователя. Исходные значения
  восстанавливаются при штатном завершении приложения.

## UUID, ключи и журналирование

UUID профиля хранится в поле `uuid` файла собственного формата профиля либо
внутри VLESS-ссылки. Подписочный кэш сохраняет тот же UUID вместе с профилем.
REALITY-профиль содержит публичный ключ и Short ID; приватный ключ должен
оставаться только на сервере.

Стартовый журнал vclient не включает UUID. Однако не следует считать все
диагностические сообщения стороннего ядра гарантированно очищенными от любых
данных: Xray-core пишет в stdout в соответствии со своей конфигурацией.
Защищайте доступ к логам и не передавайте их без проверки.

Не публикуйте реальные конфигурации, ссылки и подписки: они могут раскрыть
UUID, адрес сервера, SNI, параметры REALITY, маршруты и пользовательские
заголовки. Для примеров используйте синтетические данные. Ограничивайте
права доступа к `config.json`, `cache/subscription.json` и файлам журналов;
не храните reload-токен в публичном репозитории.

Endpoint перезагрузки Windows привязан к `127.0.0.1:9090` и требует токен в
заголовке `X-Reload-Token`. Выбирайте секрет с достаточной случайностью и не
передавайте его через недоверенные процессы.
