# Ручная проверка GUI

Автоматические проверки GUI выполняются без дисплея через `fyne/test`.
Ручные сценарии ниже необходимо выполнить на Windows или Linux с графической
средой; они не отмечены как пройденные, поскольку в текущем окружении ручной
запуск не подтверждён. Обычная desktop-сборка Fyne также требует CGo и
C-компилятор; в текущем окружении `CGO_ENABLED=0`.

- [ ] Добавить профиль по ссылке `vless://` и увидеть его в списке.
- [ ] Подключиться, увидеть статус «Подключено» и проверить внешний IP.
- [ ] Открыть логи, отфильтровать по уровню и проверить маскирование UUID.
- [ ] Сменить тему, перезапустить приложение и проверить сохранение темы.
- [ ] Убедиться, что `Ctrl+K` переключает подключение.
- [ ] Включить «Сворачивать в трей при закрытии», закрыть окно и открыть его
      через пункт трея «Показать окно».
- [ ] Через меню трея проверить подключение/отключение и пункт «Выход»;
      после выхода проверить, что порт SOCKS больше не занят.
- [ ] Включить автозапуск Windows, проверить наличие значения `vclient` в
      `HKCU\Software\Microsoft\Windows\CurrentVersion\Run`, затем выключить
      настройку и проверить удаление значения.
- [ ] Проверить, что `dist\vclient-gui.exe` запускается без консольного окна,
      показывает иконку приложения и файл `.sha256` соответствует бинарнику.
