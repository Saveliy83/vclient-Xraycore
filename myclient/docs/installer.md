# Windows-инсталлятор vclient

Инсталлятор — единый файл `dist\vclient-setup-<версия>.exe`, собранный Inno
Setup 6. Он устанавливает `vclient-gui.exe` с манифестом
`requireAdministrator`, `wintun.dll` и ярлыки, а также регистрирует удаление
через Windows «Программы и компоненты». Приложение требует elevation (UAC).

Установщик не загружает файлы из интернета и не устанавливает Go, MSYS2, GCC,
Inno Setup или другие инструменты разработки. Он также не устанавливает
отдельно Wintun-драйвер: используется DLL в комплекте с программой. Файл
`%APPDATA%\vclient` сохраняется при удалении по умолчанию. Удаление данных
возможно только после отдельного подтверждения, где по умолчанию выбран ответ
«Нет».

## Подготовка и сборка

Для сборки нужны Go, инструменты GUI-сборки проекта, официальная Wintun DLL и
Inno Setup 6. Инсталлятор не предназначен для установки этих инструментов.

1. Скачайте `wintun.dll` с https://www.wintun.net/ и поместите как
   `assets\wintun.dll`.
2. Проверьте подпись и издателя:

   ```powershell
   Get-AuthenticodeSignature .\assets\wintun.dll |
       Format-List Status,SignerCertificate
   ```

   Скрипт сборки по умолчанию требует `Status=Valid` и издателя `WireGuard LLC`.
   На конкретной копии DLL подтвердите ожидаемое имя сертификата и при
   необходимости передайте проверенное значение `-WintunPublisher`.
3. Установите Inno Setup 6. Если `ISCC.exe` не находится, сборочный скрипт
   выводит команду установки `winget install JRSoftware.InnoSetup`.
4. Соберите GUI и установщик:

   ```powershell
   .\installer\build-installer.ps1 -Version 0.1.0 -WintunPublisher "WireGuard LLC"
   ```

   Повторная сборка поверх существующего GUI требует `-Force`, например:

   ```powershell
   .\installer\build-installer.ps1 -Version 0.1.0 -WintunPublisher "WireGuard LLC" -Force
   ```

   `-SkipGuiBuild` использует существующий `dist\vclient-gui.exe` и требует
   проверяемый манифест (Windows SDK `mt.exe`). `-SignCert` подписывает только
   setup.exe при помощи Windows SDK `signtool.exe`:

   ```powershell
   .\installer\build-installer.ps1 -Version 0.1.0 -WintunPublisher "WireGuard LLC" `
       -SignCert .\certificates\vclient.pfx
   ```

   При использовании PFX signtool может запросить пароль сертификата.
   Пример использует SHA-256 и timestamp-сервис DigiCert. Документация
   Microsoft: https://learn.microsoft.com/windows/win32/seccrypto/signtool
5. Результат: `dist\vclient-setup-0.1.0.exe` и
   `dist\vclient-setup-0.1.0.sha256`. Без `-Force` существующие файлы с тем же
   именем не перезаписываются. DLL помещается в `installer\payload\` только
   после проверки подписи; payload не включается в Git.

## Установка и удаление

Перед установкой выключите VPN. Если найден
`%APPDATA%\vclient\tun-state.json`, установщик остановится и попросит
восстановить сеть приложением от администратора. Setup запускается с UAC,
предлагает закрыть запущенный GUI и при обычном запуске предлагает запустить
программу по окончании. Для ярлыка на рабочем столе включите задачу
`desktopicon`; она выключена по умолчанию.

Проверки на VM:

1. Установите от имени администратора и запустите приложение из меню «Пуск».
2. Проверьте, что при старте приложения появляется UAC и у установленного
   файла есть `requireAdministrator` манифест. `mt.exe -inputresource` можно
   использовать для извлечения манифеста. Сам `vclient-gui.exe` не подписан.
3. Удалите через «Программы и компоненты». Ярлыки и файлы приложения должны
   исчезнуть. При ответе «Нет» на «Удалить настройки и профили?» содержимое
   `%APPDATA%\vclient` сохраняется; при «Да» удаляется.
4. Установите новую версию поверх старой и убедитесь, что настройки
   сохраняются.
5. Создайте тестовый `%APPDATA%\vclient\tun-state.json` и убедитесь, что
   установка прерывается с предупреждением о восстановлении сети.

## Статус проверок

Состояние по умолчанию до выполнения проверок — **не выполнено**. Меняйте его
только после реального результата.

| Проверка | Статус |
| --- | --- |
| PowerShell Parser для `build-installer.ps1` и `verify.ps1` | выполнено автоматически |
| `installer\test-verify.ps1` (отсутствующий payload и невалидная подпись) | выполнено автоматически |
| ISCC-компиляция `installer\vclient.iss` | не выполнено |
| Создание setup и SHA256 | не выполнено |
| Установка/удаление и повторная установка на Windows VM | не выполнено |

Статус сборки не подтверждает корректность установки. Не помечайте VM-сценарии
выполненными до запуска на отдельной тестовой Windows VM без рабочих VPN
маршрутов.

## Ограничения

- Setup не подписан по умолчанию. Без подписи кода Windows SmartScreen может
  показать предупреждение. `-SignCert` подписывает установщик только если
  задан PFX и доступен `signtool.exe`; подпись должна соответствовать
  доверенному сертификату издателя.
- Установка требует UAC и административных прав. В самом GUI также встроен
  `requireAdministrator` manifest.
- Автообновление не реализовано; новую версию нужно собрать и установить
  вручную.
- Wintun DLL поставляется рядом с приложением, но драйвер автоматически не
  скачивается и отдельное управление драйвером установщик не выполняет.
- Точный издатель Authenticode Wintun DLL нужно сверять на используемом
  официальном файле; `WireGuard LLC` — значение параметра по умолчанию, а не
  результат проверки DLL в этой среде.
