# Известные проблемы

Этот список содержит ограничения и вопросы, которые не устраняются текущим
аудиторским изменением.

| Файл / место | Описание | Исправление или обход |
| --- | --- | --- |
| `cmd/vclient/main.go`, регистрация `FlagSet` | `go run ./cmd/vclient -h` не печатает справку: вывод направлен в `io.Discard`, а `flag.ErrHelp` возвращается как ошибка. | Просмотреть список опций в `docs/usage.md`. Отдельная доработка должна вывести справку и обработать `flag.ErrHelp` как штатный выход. |
| `cmd/vclient/reload_endpoint_windows.go` | Reload endpoint доступен только на Windows; адрес и порт фиксированы как `127.0.0.1:9090`. | На других системах использовать `SIGHUP`. На Windows освобождать порт 9090 и задавать `-reload-token`. |
| `cmd/vclient/main.go`, обновление подписки | При недоступности сети во время периодического обновления будет повторно применён последний кэшированный профиль. | Проверить предупреждения журнала и доступность источника подписки; успешные изменения источника применяются после восстановления сети. |

Файл кэша теперь защищается индивидуальной Windows DACL с разрешением только
текущему пользователю; на POSIX сохраняется режим файла `0600`.
