# Настройка REALITY

REALITY требует согласовать публичный ключ, короткий идентификатор и имя
сервера между клиентом и сервером. Не передавайте клиенту приватный ключ.

## Ключевая пара

На сервере выполните команду Xray:

```powershell
xray x25519
```

Команда выводит приватный и публичный ключи. Сохраните приватный ключ только
в конфигурации сервера; клиенту передайте соответствующий ему публичный ключ.
Для текущего профиля vclient публичный ключ должен быть base64url-строкой
длиной 43 символа (32 байта). Xray также может печатать значения в стандартном
base64-формате при параметре `--std-encoding`; для ссылки vless:// используйте
значение base64url без `=` на конце.

## Short ID

На сервере задайте один или несколько шестнадцатеричных идентификаторов в
`shortIds` конфигурации REALITY, например:

```json
{
  "shortIds": ["0123456789abcdef", ""]
}
```

Клиенту укажите ровно одно из значений `shortIds` в параметре `sid`. Short ID
может быть пустым; иначе он должен содержать чётное число hex-символов, не более
16. Не включайте `0x` и пробелы.

## Профиль клиента

Пример ссылки с TCP и Vision:

```text
vless://UUID@server.example.com:443?type=tcp&security=reality&pbk=PUBLIC_KEY&sid=0123456789abcdef&sni=www.example.com&fp=chrome&flow=xtls-rprx-vision#reality
```

`sni` задаёт имя `serverName`, `pbk` — публичный ключ, `sid` — short ID,
`spx` — необязательный `spiderX`, а `fp` — отпечаток клиента (по умолчанию
`chrome`). Параметр `flow=xtls-rprx-vision` поддерживается только для TCP.
REALITY поддерживается приложением для TCP, gRPC и XHTTP. Flow
`xtls-rprx-vision` допускается только с TCP. Для XHTTP задайте поля транспорта
в объекте `xhttp` профиля или в query-параметрах VLESS-ссылки.
