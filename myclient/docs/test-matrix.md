# Матрица проверок транспортов

Проверки ниже разделяют локальный запуск Xray и проверку реального прокси.
Integration-тесты запускают Xray с локальными SOCKS/HTTP inbound и проверяют,
что конфигурация принимается и listener поднимается. Они не подключаются к
указанному удалённому серверу.

| Транспорт / безопасность | Сгенерированная конфигурация | Локальный integration-тест | Внешний `curl --socks5` |
| --- | --- | --- | --- |
| TCP / none | покрыта | проходит | не запускался: нет параметров рабочего сервера |
| TCP / TLS | покрыта | проходит | не запускался: нет параметров рабочего сервера |
| TCP / REALITY, с Vision и без | golden-тесты | генерация проверяется; внешнее соединение не тестировалось | не запускался: нет параметров рабочего сервера |
| WebSocket / TLS | покрыта | проходит | не запускался: нет параметров рабочего сервера |
| HTTPUpgrade / TLS | покрыта | проходит | не запускался: нет параметров рабочего сервера |
| gRPC / TLS | покрыта | проходит | не запускался: нет параметров рабочего сервера |
| gRPC / REALITY | покрыта | проходит | не запускался: нет параметров рабочего сервера |
| XHTTP / TLS (`packet-up`) | покрыта | проходит | не запускался: нет параметров рабочего сервера |
| XHTTP / REALITY (`auto`) | покрыта | проходит | не запускался: нет параметров рабочего сервера |
| mKCP / none, MTU/TTI | покрыта | проходит | не запускался: нет параметров рабочего сервера |
| QUIC | отклоняется как неподдерживаемый | не применимо | не запускался: удалён в связанной версии Xray-core |

Внешняя проверка с `curl --socks5 127.0.0.1:1080 https://ifconfig.me` должна
выполняться с реальными UUID, адресом/портом и параметрами конкретного сервера.
Такие данные не предоставлены, поэтому внешний IP-результат не фиксировался.
Для mKCP при ручном запуске требуется флаг `-allow-experimental`. Параметры
заголовка и seed в этой версии Xray-core не применяются и намеренно отклоняются.
