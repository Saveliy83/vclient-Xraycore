# vclient

`vclient` — клиент VLESS на Go, использующий библиотеку ядра Xray-core для
подключения к удалённому серверу и предоставления локальных SOCKS5 и HTTP
прокси. Клиент принимает ссылку VLESS, собственный JSON-профиль или профиль из
подписки.

vclient предоставляет обычные локальные SOCKS5/HTTP-прокси и, на Windows,
опциональный режим полного туннеля через TUN. Полный туннель требует прав
администратора и `wintun.dll`; системные IPv4-маршруты перенаправляются через
VPN. IPv6 по умолчанию временно отключается на физических адаптерах; если
блокирование IPv6 выключено, IPv6 может идти напрямую вне VPN. При потере
соединения клиент пытается убрать TUN-маршруты и восстановить прямой доступ.
Это не гарантия анонимности и не kill switch. vclient не обходит блокировки и
не проверяет правомерность доступа к удалённому серверу.

## Требования

- Go **1.27.2** или совместимая версия, удовлетворяющая директиве `go` в
  [go.mod](./go.mod).
- Windows 10/11 или Linux.
- В проекте используется библиотека Xray-core
  **v1.260327.0**. Отдельно устанавливать исполняемый файл `xray` для сборки и
  запуска vclient не требуется.

### Установка Go на Windows

1. Скачайте установщик Go с [go.dev/dl](https://go.dev/dl/) и установите его.
2. Установщик обычно добавляет Go в `PATH`. Если команда `go` не находится,
   добавьте каталог установки Go, обычно `C:\Program Files\Go\bin`, в
   переменную среды `Path`.
3. Закройте и заново откройте PowerShell, затем проверьте установку:

```powershell
go version
```

Команда должна вывести версию Go. Если нет — проверьте `PATH` в настройках
переменных среды и перезапустите терминал.

## Сборка

Из корня проекта:

```powershell
go build -o vclient.exe ./cmd/vclient
```

В Linux:

```bash
go build -o ./vclient ./cmd/vclient
```

Сборка графического приложения Windows без консольного окна и контрольной
суммой SHA-256:

```powershell
.\build.ps1 -Target gui -Version 0.1.0
```

Если `dist\vclient-gui.exe` уже существует, добавьте `-Force`, чтобы явно
разрешить его замену. Бинарник, Wintun DLL и файл контрольной суммы появятся в
`dist\`. До сборки положите официальный `wintun.dll` с сайта
https://www.wintun.net/ в `assets\wintun.dll`. Перед использованием проверьте
Authenticode-подпись:

```powershell
Get-AuthenticodeSignature .\assets\wintun.dll | Format-List Status,SignerCertificate
```

Продолжайте только если статус подписи `Valid` и издатель ожидаемый. DLL не
входит в репозиторий. Сборка встраивает манифест `requireAdministrator` через
MinGW `windres`, поэтому при запуске Windows покажет запрос UAC. Можно задать
версию переменной окружения `VCLIENT_VERSION`; если она не задана, скрипт использует
`git describe --tags --always --dirty`, а при недоступном Git — `dev`.
Desktop-сборка Fyne требует установленного C-компилятора и включённого CGo.
Для MSYS2 установите GCC и binutils командой
`pacman -S mingw-w64-ucrt-x86_64-gcc mingw-w64-ucrt-x86_64-binutils` и
добавьте `C:\msys64\ucrt64\bin` в `PATH`.

### Сборка установщика

Для создания установщика нужен Inno Setup 6 (компилятор ISCC). Сборка
установщика не устанавливает инструменты разработки и не загружает DLL:

```powershell
.\installer\build-installer.ps1 -Version 0.1.0 -WintunPublisher "WireGuard LLC"
```

Если setup с этой версией уже есть, используйте `-Force` для явной замены.
Параметр `-SkipGuiBuild` использует существующий GUI-бинарник, а `-SignCert`
передаёт PFX для подписи setup.exe. Без сертификата установщик остаётся
неподписанным, и Windows SmartScreen может показать предупреждение. Подробные
требования, проверка подписи Wintun и сценарии установки описаны в
[документации установщика](./docs/installer.md).

### Установка для пользователя

Скачайте `dist\vclient-setup-<версия>.exe` и запустите установщик. Установка
требует подтверждения UAC. Установщик ставит приложение и Wintun DLL из
встроенного payload, создаёт ярлык в меню «Пуск»; ярлык на рабочем столе
необязателен. При удалении настройки и профили сохраняются, если явно не
подтвердить их удаление. Для portable-режима можно использовать GUI-бинарник
вместе с проверенной `wintun.dll`.

### Графический интерфейс

1. Скачайте и распакуйте `dist\vclient-gui.exe` (или соберите его командой выше).
2. Запустите `vclient-gui.exe`, откройте раздел «Профили» и добавьте ссылку
   `vless://` либо импортируйте профиль.
3. Откройте «Подключение», выберите профиль и нажмите «Подключиться». Для
   проверки используйте «Проверить IP»; приложения можно направить на SOCKS5
   `127.0.0.1:1080` или HTTP `127.0.0.1:1081`.

В разделе «Настройки» можно включить сворачивание в системный трей при закрытии
окна и автозапуск Windows. В трее доступны показ окна, подключение/отключение
и штатный выход с остановкой ядра. Фреймворк Fyne предоставляет для трея меню,
но не отдельное событие левого клика по иконке; используйте пункт меню
«Показать окно».

Для полного туннеля откройте «Подключение», включите «Весь трафик Windows
через VPN (TUN)», подтвердите изменение маршрутов и подключитесь к профилю.
Firefox и другие приложения без настроек прокси тогда используют VPN. Для
возврата к обычному режиму отключите TUN в том же разделе. При включённом по
умолчанию `BlockIPv6` приложение сохраняет IPv6 binding физических адаптеров в
recovery-файл и временно отключает IPv6 на них. При ошибке отключения
выполняется откат уже изменённых адаптеров; при штатном выключении VPN
исходные значения восстанавливаются. Внешний IPv6 в этом режиме недоступен,
поскольку IPv6 через TUN не маршрутизируется. При выключенном `BlockIPv6`
IPv6 остаётся включённым и может идти напрямую вне VPN; через TUN
перенаправляется только IPv4. Перед использованием проверьте сценарии на
тестовой машине по [чек-листу TUN](./docs/tun-checklist.md). Возможны конфликты
с другими VPN, сетевым сном и сторонними сетевыми фильтрами. После аварийного
завершения vclient сохраняет recovery-файл с PID и временем запуска процесса,
который проверяется при следующем старте.

Для включения изображения в пакетах Fyne сначала установите утилиту и затем
сгенерируйте Go-ресурс из `assets/icon.png`:

```powershell
go install fyne.io/tools/cmd/fyne@v1.7.3
fyne bundle -package gui -name bundledIcon -o internal/gui/icon_generated.go internal/gui/icon.png
```

В проекте PNG уже встроен в приложение через `//go:embed`; указанная команда
нужна только при ручном обновлении сгенерированного ресурса. Для упаковки
проверьте доступные параметры вашей версии командой `fyne package -h`;
актуальный синтаксис Fyne CLI использует `-os`, `-icon`, `-name` и `-app-id`.
Команда упаковки для Windows:

```powershell
fyne package -os windows -icon assets/icon.png -name vclient -app-id com.example.vclient
```

## Быстрый старт

Подставьте реальные UUID и адрес сервера. Команда запускает приложение и
оставляет его работать до Ctrl+C:

```powershell
go run ./cmd/vclient -link "vless://UUID@server.example.com:443?type=tcp&security=tls&sni=server.example.com#my-server"
```

В другом терминале проверьте выход через локальный SOCKS5:

```powershell
curl.exe --socks5 127.0.0.1:1080 https://ifconfig.me
```

На Linux используйте те же команды `go run` и `curl`. `UUID` и имя сервера в
примере — заполнители, их необходимо заменить значениями, предоставленными
администратором VLESS-сервера.

## Настройка приложений

Укажите SOCKS5-прокси `127.0.0.1`, порт `1080`. Если приложение позволяет
выбрать DNS через прокси, включите эту настройку. Для HTTP-прокси укажите
`127.0.0.1:1081`.

Например, в настройках браузера выберите ручную настройку прокси:

- SOCKS Host: `127.0.0.1`, Port: `1080`, SOCKS v5;
- HTTP Proxy: `127.0.0.1`, Port: `1081`.

Обычно браузеру задают один тип прокси — SOCKS5 или HTTP — согласно доступным
настройкам браузера. Флаг `-system-proxy` на Windows может настроить системный
прокси пользователя, но приложения могут игнорировать системные настройки.
На Linux этот флаг не меняет системный прокси.
